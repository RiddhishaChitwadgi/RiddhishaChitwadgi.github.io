# Riddhisha Chitwadgi - Portfolio Website

A professional, interactive portfolio website showcasing my work as a Data Engineer and Analyst.

![Portfolio Preview](https://via.placeholder.com/https://riddhishachitwadgi.github.io/)

## 🌟 Features

- **Interactive Design**: Smooth animations and transitions throughout
- **Custom Cursor**: Personalized cursor with hover effects
- **Typing Animation**: Dynamic title rotation
- **Scroll Animations**: Elements reveal as you scroll
- **Filterable Content**: Filter projects and skills by category
- **Responsive Design**: Works perfectly on all devices
- **Dark Mode Support**: Automatic based on system preference
- **Contact Form**: Functional contact form with validation
- **Project Modals**: Detailed project information in popups

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Custom properties, animations, flexbox, grid
- **JavaScript (ES6+)**: Modern JavaScript features
- **Font Awesome**: Icons
- **Google Fonts**: Inter and Playfair Display fonts
